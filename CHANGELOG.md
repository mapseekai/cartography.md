# Changelog

All notable changes to cartography.md will be documented here.

中文版：[CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md)

The project follows semantic versioning for the format and npm package.

## 0.1.0 - 2026-08-28

### Added

- Initial `CARTOGRAPHY.md` draft specification.
- Deterministic YAML front matter plus canonical Markdown sections.
- Map intent, data bindings, zoom bands, tokens, scales, encodings, layer order, accessibility, MapLibre, validation, and agent-behavior contracts.
- Optional `DATA_PROFILE.json` companion format.
- TypeScript parser, schemas, linter API, style-contract validator, and diff API.
- CLI commands: `lint`, `parse`, `diff`, `rules`, and `spec`.
- Official MapLibre Style Specification validation integration.
- OpenFreeMap Bright example adopting a public production style, with governance metadata, a data profile, and third-party license notices.
- JSON Schemas, CI workflow, and Agent skill guidance.
