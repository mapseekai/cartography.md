# 设计哲学

cartography.md 把地图设计系统看作持久的视觉身份，而不是一张临时的生产配方。一份 `CARTOGRAPHY.md` 应当在任务、数据集、工具链和输出形式都改变之后依然可用。

English: [PHILOSOPHY.md](PHILOSOPHY.md)

## 正文承载设计

专业的制图判断无法压缩成一张属性清单。文档的 Markdown 正文应当描绘一个鲜明、可辨认的视觉世界：什么应当安静、什么应当紧迫，什么值得吸引目光，密度如何收放，哪些取舍守护着可读性，哪些做法绝不能侵蚀家族气质。

空泛的形容词没有意义。“干净、现代”几乎给不了 Agent 任何指引；“温暖的纸色、清淡的水色、节制的墨色、宽松的标注间距”才构成一个足以支撑大量决策的世界。

## Token 提供精确的上下文

Token 存在于真正需要精确与复用的位置：色彩、字体排印、线宽、尺寸、透明度、间距与虚线节奏。它们让正文引用同一套稳定词汇，也防止细小数值在一次次使用中悄悄漂移。

Token 是设计判断的上下文，而不是面向某个生产目标的指令。每个引用都必须能在同一文档内解析，且解析不得改变值的类型。当精确值与正文发生工具可以判定的矛盾时，以 Token 为准，并应报告这一矛盾。

## 元素把词汇组合成组件

只有词汇不构成风格。元素（elements）把 Token 组装成可复用的制图组件：主要的线、上下文标注、安静的面。`family`、`role` 与 `state` 让同一个想法保有几种协调的变体，而不必为每个变体另起新名。

元素始终只是设计意图。它不记录数据字段、图层标识或渲染器属性；与真实数据及目标平台/渲染环境的映射交给外部的 data-profile 和适配器，按任务、按渲染器分别决定。

## 身份超越变化的内容

经得起时间的设计系统描述的是关系，而不是当前的资产清单。它规定哪些语义角色应当安静、提供上下文、成为焦点、表示选中或发出警示，而不记录今天的字段名或对象列表。这样，同一个视觉家族可以从容面对陌生内容，而不必假装未知的事实已经明了。

Agent 在应用这套身份时必须保住语义。强调可以让选中对象更易找到，但不能把普通对象变成警告，也不能抹掉上下文与焦点之间的界限。

## 层级是组织原则

每一个视觉选择都参与层级。背景、上下文、主体、焦点与关键状态，应当通过彼此协调的对比、粗细、大小、间距与纹理保持可分。注意力是有限的：一切都被强调，等于什么都没有强调。

因此，构图与层叠应当被描述为长期稳定的关系，而不是当前对象的列表。文档应当讲清楚：地图变密时什么先退让，哪些信息必须留住呼吸的空间。

## 比例尺是渐进呈现

比例尺行为应当描述可辨认的阅读阶段——概览、区域、局部、细节——而不是写死某个渲染器的 zoom 阈值。远观时保住大的空间格局；拉近后，以有意设计的节奏显露局部结构。简化、聚合、标注密度与符号细节都可以变化，视觉家族却必须保持连续。

问题从来不只是什么出现、什么消失，而是每个阶段是否仍在传达同一种层级与同一份身份。

## 状态保留底层含义

悬停、选中、警示、无效等临时状态也是视觉语言的一部分。它们应当清晰可辨，却不破坏对象本来的基础角色，也不遮蔽周围的上下文。

含义关键时，状态区分不能只靠色相。形状、轮廓、图案、粗细、位置与措辞可以构成冗余线索，让警示与选中始终泾渭分明。

## 包容性是设计约束

包容性属于长期的设计判断，既不是事后补缀，也不是一张机器勾选的清单。早期草案曾声明可供机器校验的对比度组合；现行格式有意把对比度与包容性指引放回正文——冗余编码、小字号可读性、密度容忍度、关键状态的处理，这些判断超出了一份文档 Schema 能够诚实验证的范围。

把目标写进正文：期望的对比度基准、色相之外的备用线索、无法满足要求时的降级策略。文档校验的范围本就有意窄于完整的无障碍评审；真实产出仍须在实际使用环境中评估。

## 保留核心不理解的内容

格式向自定义根字段与未知内容开放：它们与标准词汇比邻而居，不需要指定的扩展位。解析器与工具应当保留自己无法解释的信息。与标准键仅大小写不同的疑似笔误可以给出警告，但不熟悉的内容绝不能仅仅因为当前核心没有意见就被静默丢弃。

这条保留规则让专业社群可以自由扩展文档，而不必把每个领域关切都硬塞进公共 Schema。

## 只验证可确定的内部事实

核心校验有意限定在文档范围内。它可以检查受限的 YAML 写法、front matter 的 Schema、章节结构、引用解析、解析后的 Token 与元素属性类型，以及声明的章节省略。它无法推断正文的质量、当前数据的真伪、任务是否适配，也无法断言产出物是否成功。

这条边界让诊断保持诚实：凡事实可判定之处，自动化应当严格；凡需要专业评审与运行时上下文之处，边界应当标明。
