# 从 0.3.0 迁移到 0.4.0

0.4.0 保留 YAML Token、代表性元素和 Markdown 设计意图，但改变了视觉解释契约。只修改 `version` 不代表迁移完成。0.4.0 parser 拒绝 0.3.0 文件；完成语义核查前应保留原文。

逐项审查受影响元素，将迁移决定记录在设计文档之外：

| 属性 | 必须确认的事项 |
|---|---|
| `size` | 旧值表示半径、直径、图标宽度还是缩放系数？新值为主体旋转前包围盒长边，圆形用直径。只有确认旧值为半径才乘二；图标保持长宽比。 |
| `strokeWidth` | 主描边完整宽度，不含套线、外轮廓和光晕。 |
| `casingWidth` | 新值为每侧厚度。如果确认旧值为底线总宽 B、主线宽 W，则同单位时换算为 (B − W) / 2。 |
| `outlineWidth` / `haloWidth` | 从主体或字形外缘向外扩展，不改变名义主体尺寸。确认历史约定。 |
| 透明度 | 保留颜色 Alpha 和局部透明度，组件内部绘制后施加整体透明度。核查旧 renderer 的合成行为，报告近似。 |
| `offset` / `spacing` | 非零偏移说明参照、方向和正负含义；间距说明边缘净距、中心距、重复距或外围版式间距。偏移保留字面量或扩展，不放入非负标准组。 |
| 尺度 | 指定基础阶段、允许替换、显隐和不变量，不为任务或引擎重定义 Token。 |
| 状态 | 区分家族职责与 critical/invalid/selected/hover；显式定义组合元素，语义状态优先于操作反馈。 |

将尺寸和间距从 widths 分离；不得仅因数值相同合并水系和道路 Token。审查全部 Typography 字段并保留未知扩展。来源文件名、统计、具体比例尺、过滤器和转换疑问进入 `INIT_REPORT.md` / `INIT_REPORT.json`。

解决以上问题后，才修改 `version: "0.4.0"`，分别执行并报告格式校验、设计评审、目标验证和视觉评审。自动迁移工具可以处理结构确定的修改并生成 TODO/报告，不得猜测历史 size、casing、role/state 或尺度基准的含义。
